# 离线密钥 Web

基于 MPW v3 的本地密码生成器。应用没有账户或后端，所有密钥派生和密码生成均在浏览器中完成。

## 使用流程

1. 在解锁页输入完整姓名和主密码，应用在内存中派生当前会话密钥。
2. 搜索或选择最近使用的网站，也可以输入新网站，然后点击“生成密码”。
3. 模板和计数器位于默认收起的高级选项中。
4. 点击右上角锁定按钮可立即清除姓名、主密码、派生密钥和生成结果。

刷新或关闭页面后必须重新解锁。姓名、主密码、派生密钥和生成结果不会写入浏览器存储。

localStorage 的 `mpw.site-history` 只保存网站、模板、计数器和最近使用时间。历史记录不设条数上限。

解锁前后均可点击顶部主题按钮，在浅色、深色和跟随系统模式间循环切换。主题偏好保存在 localStorage 的 `mpw-web-theme` 中，不包含身份或密码信息。

## 二维码迁移

解锁后点击顶部的二维码按钮，可以将全部网站历史迁移到另一台设备：

1. 导出设备使用当前 MPW 身份派生的专用迁移密钥，加密并压缩全部历史。
2. 数据较大时会完整拆分为多张自动轮播的二维码，不会裁剪记录。
3. 手机可用后置摄像头连续扫描；没有摄像头的电脑可一次选择多张二维码截图。
4. 所有二维码收齐并通过认证后，导入历史与本地历史合并。

只有使用相同完整姓名和主密码解锁的设备才能解密二维码。二维码不包含姓名、主密码、派生主密钥或生成结果。迁移是离线快照合并，不是后台同步；删除操作不会传播，任一设备仍保留的记录可能在之后的迁移中重新出现。

## 开发

从仓库根目录运行：

```bash
npm install
npm run dev
npm run check
npm run build
```

生产构建包含 PWA manifest 和离线 Service Worker。Service Worker 发现新版本后，应用会显示更新提示；点击“立即更新”会刷新页面并重新要求解锁，网站历史仍会保留。
